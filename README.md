```

```

```
python main.py --test 1 2 3 4

python main.py --test 1
```

2 - mazs tests (6 kursi, 5 studenti; cikli 1-2-3 + cikls 3-4-5-6-1 -> minimālais skaits: 3 laiki);

3 - (nejaušais) vidējais piemērs ar 40 studentiem un 12 kursiem un *nejauši* izvēlētām reģistrācijām;

4 - (nejaušais) lielais piemērs ar 200 studentiem un 33 kursiem un *nejauši* izvēlētām reģistrācijām.
